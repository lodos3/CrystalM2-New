# Directional wing height review

Physical wings (selectors 2–16) use one canonical upright membrane height and crown per design. Horizontal span and rear sweep still change with facing; socket placement, art-root pinning, depth shells and particles remain. Neutral geometry no longer uses direction-dependent crown height, transverse Y shear, rear Y shear or side-only feather compression. Attack pitch applies bounded distal lift without moving the root. Selectors 0–1 retain authored legacy pose textures; selectors 17–19 are orbital auras, not hinged membranes. Those five are included in visual metrics but not the physical-membrane invariance assertion.

Windows regression: `dotnet run --project Tests/WindowsRendererTests -- --wing-first-poses "path/to/00.Lib" "path/to/review"`. Uses the actual game emitter, D3D11 WARP rasterizer and decoded 00.Lib silhouettes; 20 selectors × two classic body banks × eight directions × 19 distinct action sequences plus Attack4 alias = 6400 requested views. Each GIF contains one 8-facing sheet. CSV records pre-occlusion and visible wing height, width, root-relative extents and overlap. Legacy fishing has no authored wing sequence and is flagged missing rather than substituted. Death/fishing poses are diagnostic, not a claim that wings are visible in those states in game. GPU results and visual checks must be run locally; geometry tests do not establish perceived size equality of authored legacy textures or orbiting auras.
